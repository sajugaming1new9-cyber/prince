# My Universe — Personal Profile Website

## Files
- `index.html` — website
- `profile.jpg` — add your own profile photo with this exact filename
- `song.mp3` — add an MP3 you have permission to use with this exact filename

## Customize
Open `index.html` in an editor and replace:
- `YOUR NAME`
- `YOUR_USERNAME`
- `8801XXXXXXXXX` (WhatsApp number with country code, digits only)
- `YOUR CITY / COUNTRY`
- Bio and About text
- Social URLs

For IMO, use a public profile/contact link if you have one. If you don't have a shareable IMO link, change that button to your preferred contact instructions.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `profile.jpg`, and `song.mp3`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages URL to appear.

Note: Most mobile browsers block audio autoplay until the visitor taps the page. This site includes a Play Music button for that reason. Use music you own or are allowed to share.
